# خريطة الحرم والمشاعر

أُضيفت المناطق إلى المشروع الموجود، مع الحفاظ على واجهات اللغات وسراج.

انظر [الإصلاحات الهندسية وتنظيم الطوابق](REPAIRS.md) للتغييرات اللاحقة للمقارنة الرسمية.

## المشاهد

- الحرم: المشهد الأصلي بطوابقه والمطاف والمسعى.
- الأبراج: سبعة أبراج أصلية هندسية، أربعة أوجه للساعة وعقارب وعلامات هندسية، هلال، ساحة، مصعد وشرفة تجريبية.
- منى: مخيمات ذات خيام ثلاثية الأبعاد بـ InstancedMesh، جسر الجمرات وثلاثة مستويات، الجمرات الثلاث، مصعد وسلالم، دورات مياه ومياه وإسعاف ولقاء.
- مزدلفة: ساحة، نموذج مسجد المشعر الحرام، مخيمات وخدمات.
- عرفات: نموذج جبل الرحمة ومعلمه، توجيه إلى السفح، نموذج مسجد نمرة، مخيمات ونخيل وخدمات.

## التشغيل

```sh
cd ~/Documents/Playground/siraj/sakina
npm install
npm run dev -- --port 5179
npm test
npm run build
```

المنفذ 5178 كان يخدم النسخة القديمة في `~/Documents/Playground/sakina`، ولذلك تستخدم معاينة هذه النسخة 5179.

## الاستخدام

اختر المنطقة من الشريط أعلى الخريطة. اختيار منطقة يستكشفها فقط، ولا ينقل موقع المستخدم. زر «محاكاة من هنا» يضع الموقع الافتراضي عند مدخل المنطقة ويبدأ مسارًا إلى معلمها الرئيسي. تستطيع اختيار أي علامة أخرى ثم التوجيه إليها وتشغيل الحركة. جميع المناطق متصلة بشبكة Dijkstra، مع مسارات للمصاعد وتجنب السلالم عند تشغيل إمكانية الوصول، وبدائل عند إغلاق الممر الرئيسي في الحرم ومنى وعرفات.

التنقل بين المستويات يحافظ على الموقع والمسار. تستعيد الرحلة المحفوظة الإحداثيات والوجهة ونسبة التقدم والمنطقة. تظل عدادات العمرة الأصلية محفوظة عند استكشاف المشاعر؛ هذه الإضافة لا تدعي تنفيذ نظام كامل لحساب واجبات الحج أو مواعيده.

## حدود البيانات

المجسمات أصلية ومبسطة؛ لا ملفات نماذج من الموقع الرسمي. جميع الإحداثيات محلية وتجريبية. المسافات بين المشاعر مضغوطة لتسهيل عرضها في مشهد واحد، والمسار بينها اتصال توضيحي وليس توجيهًا ميدانيًا أو مسار نقل معتمدًا. الإشغال وإغلاقات الممرات والخدمات محاكاة. لا يحدد النموذج حدود عرفات الشرعية أو مواقع حملات فعلية. لا يدعي قياسًا فعليًا لمعدل 60 FPS.

أسماء المعالم وتسلسل المناطق راجعت بالرجوع إلى:
- https://hajj.nusuk.sa/Journey
- https://hajj.nusuk.sa/nusuk/hajj-rituals
- https://awqaf.gov.sa/en/endowment-models/mecca-towers

## الملفات

`geography.ts`: بيانات المناطق وعقد الشبكة والأماكن وترجماتها إلى اللغات السبع.
`RegionalScene.tsx`: الأبراج والخيام والجمرات والمشاعر.
`RegionNavigator.tsx`: اختيار المنطقة والمحاكاة المحلية.
`navigation.ts`: إدماج الشبكة الجديدة وحساب الطرق.
`store.ts`: اختيار المنطقة، حفظها واستعادتها، والإغلاقات المحلية.
`Scene.tsx`: حدود الكاميرا والإضاءة وطبقات الطريق والموقع.
`regions.test.ts`: اختبارات المناطق والإتاحة والإغلاق والاستعادة والتكامل.
