# Manual terminology QA checklist

Not code - a sign-off checklist for a human (ideally a native/religious-
literate speaker per language) to fill in before the multilingual feature
is trusted for production. The terms below come from
`i18n/glossary.py::KEY_TERMS`. Run `tests/manual_live_translation_check.py`
first to get real translated output to check against, or test these terms
directly via the voice prototype / `i18n.service.ask_multilingual`.

For each row: does the translated term/phrasing correctly and respectfully
convey the Islamic ritual meaning (not just a literal dictionary
translation)? Mark ✅ / ❌ / ⚠️ (needs discussion) per language, with notes.
